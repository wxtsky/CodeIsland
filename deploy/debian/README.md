# CodeIsland Debian Distribution Node & Webhook Deployment

This guide documents the setup required to connect a self-hosted Debian server (running Nginx and a Cloudflare Tunnel) to the GitHub Actions release pipeline.

---

## Architecture

```
Developer
  │ git tag vX.Y.Z && git push
  ▼
GitHub Actions (macos-15)
  │ 1. Compile native ARM64 binary
  │ 2. Assemble CodeIsland.dmg
  │ 3. Sign with Sparkle Ed25519 key
  │ 4. Create GitHub Release
  │ 5. Trigger Webhook via Cloudflare Tunnel (authenticated with X-Webhook-Secret)
  ▼
Cloudflare Edge
  │ Encrypted HTTPS ingress
  ▼
Debian Server (Nginx :80)
  │ Proxy /api/deploy-webhook
  ▼
Webhook Daemon (:9000)
  │ Execute deploy-codeisland.sh
  ▼
Local Storage (/var/www/codeisland-updates/)
  ├── Download CodeIsland.dmg and appcast.xml
  ├── Verify SHA-256 checksum
  ├── Atomic swap: appcast.xml and latest.dmg symlink
  └── Retention policy: prune releases older than the latest 5 builds
```

## Debian Server Setup

### 1. Run Node Setup Script
Copy the `deploy/debian/` directory to the Debian server and execute:

```bash
sudo ./deploy/debian/setup-debian-node.sh
```

The script performs the following tasks:
- Installs `webhook`, `curl`, and `jq`.
- Creates `/var/www/codeisland-updates/releases/` with `www-data` ownership.
- Generates a cryptographically random 32-character `WEBHOOK_SECRET`.
- Configures and starts the systemd service `codeisland-webhook.service` on `127.0.0.1:9000`.

> [!IMPORTANT]
> Record the `WEBHOOK_SECRET` printed at the end of the script output. It is required for the GitHub repository secret configuration.

---

### 2. Configure Nginx
Copy the Nginx configuration template to `sites-available`:

```bash
sudo cp deploy/debian/nginx-updates.conf /etc/nginx/sites-available/codeisland-updates.conf
```

Edit the file to set the `server_name` to match your designated Cloudflare Tunnel domain:

```bash
sudo nano /etc/nginx/sites-available/codeisland-updates.conf
# Replace: server_name updates.yourdomain.com;
```

Enable the configuration and reload Nginx:

```bash
sudo ln -s /etc/nginx/sites-available/codeisland-updates.conf /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx
```

---

### 3. Cloudflare Tunnel Routing
Ensure your Cloudflare Zero Trust tunnel configuration routes the chosen hostname to the local Nginx instance on port 80:

```yaml
ingress:
  - hostname: updates.yourdomain.com
    service: http://localhost:80
  - service: http_status:404
```

## GitHub Repository Secrets Configuration

Navigate to **Settings > Secrets and variables > Actions > New repository secret** and define the following variables:

| Secret Name | Description | Example / Format |
|---|---|---|
| `WEBHOOK_URL` | Public webhook endpoint routed through Cloudflare Tunnel | `https://updates.yourdomain.com/api/deploy-webhook` |
| `WEBHOOK_SECRET` | Secret token generated by `setup-debian-node.sh` | 32-character random string |
| `SPARKLE_PRIVATE_KEY` | Private Ed25519 key used to sign the update bundle | Base64-encoded string |

## Release Execution & Verification

### Triggering a Release

#### Method 1: Semantic Version Git Tag
```bash
git tag v1.0.41
git push origin v1.0.41
```

#### Method 2: GitHub Actions Manual Dispatch
1. Go to the **Actions** tab in the repository.
2. Select **Deploy macOS Release (Sparkle + Debian Webhook)**.
3. Click **Run workflow**, input the target version (e.g., `1.0.41`), and trigger the run.

## Monitoring and Logs on Debian

Check webhook service status and recent execution logs:
```bash
journalctl -u codeisland-webhook.service -f
```

Inspect published files in the web root:
```bash
ls -la /var/www/codeisland-updates/
ls -la /var/www/codeisland-updates/releases/
```

Verify the Sparkle update feed endpoint:
```bash
curl -I https://updates.yourdomain.com/appcast.xml
```
